# Apiary 蜂巢项目
Apiary 是一个基于 Python + Tkinter + SQLite + Ollama 的无人机任务调度与仿真项目，用于模拟多机协同、任务分配、局部避障和信号场安置。它既适合作为桌面练习工具，也可以作为无人机任务调度逻辑的原型实验平台。

该项目的核心目标是：

使用任务优先级与队列管理处理多任务请求
在运行时维护无人机状态和局部信号设置
支持AI参与任务解析、宏观分配和局部路线建议（与局部分配规则的边界见下文）
底层移动由仿真规则执行，看似紫色危险落点进行拦截
将任务持久化到 SQLite；每次启动重新初始化演示任务，飞行状态和大部分运行参数仅保存在内存中
